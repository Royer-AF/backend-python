# 🐍 Python Backend Development Lab

¡Bienvenido a mi laboratorio de aprendizaje y desarrollo Backend con Python! Este repositorio documenta mi progreso desde los fundamentos del lenguaje hasta la construcción de APIs RESTful asíncronas con almacenamiento persistente.

> **Entorno de desarrollo:** Linux Mint XFCE - Windows 11 | Visual Studio Code | Python 3.x

---

## 🚀 Progresos y Temas Cubiertos

### 📌 Nivel 1: Fundamentos y Lógica de Programación

- [x] Control de flujo (`if`, `else`, bucles `for` / `while`).
- [x] Estructuras de datos (`listas`, `diccionarios`, `tuplas`).
- [x] Funciones modulares, argumentos y retorno de datos.

### 📌 Nivel 2: Programación Orientada a Objetos (POO) & Persistencia Local

- [x] Clases, instancias y el uso de `self`.
- [x] Herencia y reutilización de código mediante `super()`.
- [x] Manejo de archivos planos y serialización de datos con **JSON** (`json.dump`, `json.load`).

### 📌 Nivel 3: Desarrollo de APIs Web (FastAPI)

- [x] Fundamentos de arquitectura Cliente-Servidor y protocolo HTTP.
- [x] Creación de servidores web asíncronos con **FastAPI** y **Uvicorn**.
- [x] Definición de rutas y **Endpoints** (`GET` y `POST`).
- [x] Parámetros de ruta dinámicos (`/productos/{id}`).
- [x] Validación de datos en tiempo real mediante **Pydantic** (`BaseModel`).
- [x] Documentación interactiva automática con **Swagger UI** (`/docs`).
- [x] Integración de persistencia JSON en endpoints HTTP.

---

## 🛠️ Tecnologías Utilizadas

- **Lenguaje:** Python
- **Framework Web:** FastAPI
- **Servidor ASGI:** Uvicorn
- **Validación de Datos:** Pydantic
- **Entorno OS:** Linux Mint XFCE - Windows 11
