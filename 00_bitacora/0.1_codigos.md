## Crear y activar el entorno virtual:

- python3 -m venv .venv
- source .venv/bin/activate

## Instalar las dependencias:

- pip install -r requirements.txt

## Levantar la API principal con FastAPI:

- uvicorn main:app --reload

## Probar los Endpoints:

- API: Abre en tu navegador http://127.0.0.1:8000/productos/1
- Swagger Docs: Explora http://127.0.0.1:8000/docs
